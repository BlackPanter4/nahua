# NAHUA
## un Android echo para rescaté

![Comandante Joe - Piloto NAHUA](nahua-piloto.jpg)

**Comandante Joe | NAHUA RESCUE COMMANDER**
🇲🇽 Hecho en Parral, Chihuahua

> **210 BAR** de presión hidráulica | Guante de control con micro-pulsos
> Misión: Donde no entra una retro, entra NAHUA.

### Sistemas
- HPU 20L + Válvula 4/3 ESP32 PWM 20kHz
- Fuerza de levante: 500kg por losa/vigueta
- Control: Joysticks + guante flex
